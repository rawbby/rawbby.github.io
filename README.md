# rawbby.github.io

Personal website, published at [robert-fritsch.de](https://robert-fritsch.de) by GitHub Pages
(Jekyll, theme minima) on every push to `main`.

| File | Page |
|---|---|
| `index.md` | About (home): intro, how it started, industry, research, education, contact |
| `posts.md` | List of posts |
| `assets/<post>/` | Figures of a post (SVG, converted from the thesis PDFs with `pdftocairo -svg`) |
| `_posts/YYYY-MM-DD-<slug>.md` | One post each, published at `/posts/<slug>/` |
| `_config.yml` | Site settings, navigation order |
| `CNAME` | Custom domain |
